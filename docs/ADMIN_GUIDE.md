# 👑 ڕێنمایی ئەدمین — Admin Guide

## 🎯 دەستپێکردن

بۆ چوونە ژوورەوە وەک ئەدمین:

1. کلیک لە **🔐 چوونەژوورەوە**
2. مۆبایل و پاسۆرد دابنێ
3. دوای پەسەندکردن، لە Drawer کلیک لە **👑 پانێڵی ئەدمین**

---

## 📊 پانێڵی ئەدمین

### ئامارە سەرەکییەکان

لە سەرەوەی پانێڵ، دەبینی:

- 🏪 **کۆی شوێنەکان**
- 📋 **سکاڵای چاوەڕوان**
- 🛍️ **کۆی کاڵاکان**
- 👑 **داواکاری ئەدمین**

### بەشەکانی پانێڵ

| بەش | ناوەڕۆک |
|-----|--------|
| ⚡ **بەشی گرنگ** | فریاکەوتن، ڕووداوەکان، سکاڵاکان |
| 🏪 **شوێنەکان** | شوێن، کاتێگۆری، گەڕەک |
| 📰 **ناوەڕۆک** | هەواڵ، ڤیدیۆ، سلاید |
| ⚡ **خزمەتگوزاری** | ئاگاداری، کەشوهەوا، سووتەمەنی، دراو |
| ⚙️ **سیستەم** | داواکاری، داتابەیس |

---

## 🚑 بەڕێوەبردنی فریاکەوتن

1. کلیک لە **🚑 بەڕێوەبردنی فریاکەوتن**
2. کلیک لە **➕ زیادکردنی خزمەتگوزاری**
3. پڕی بکەرەوە:
    - ناوی کوردی
    - ژمارەی پەیوەندی
    - کەرت (پۆلیس، ئاگرکوژێنەوە، ئەمبولانس...)
    - ناوی فەرمانگە
    - ئایکۆن و ڕەنگ
4. پاشەکەوت

---

## 📅 بەڕێوەبردنی ڕووداوەکان

1. کلیک لە **📅 بەڕێوەبردنی ڕووداوەکان**
2. کلیک لە **➕ ڕووداوی نوێ**
3. پڕی بکەرەوە:
    - ناونیشان
    - کەرت (نیشتمانی، ئاینی، وەرزشی، کلتوری)
    - بەروار و کات
    - شوێن
    - وێنە (URL)
4. پاشەکەوت

---

## 📋 بەڕێوەبردنی سکاڵاکان

1. کلیک لە **📋 بەڕێوەبردنی سکاڵاکان**
2. لیستی سکاڵاکان دەردەکەون
3. فلترەکان:
    - **دۆخ** (چاوەڕوان، پەسەندکراو، تەواو، ڕەتکراو)
    - **فلتەری تر**
4. کلیک لە سکاڵایەک → وردەکاری:
    - ✅ پەسەندکردن
    - ❌ ڕەتکردنەوە
    - ✅ تەواوکردن
    - 🗑️ سڕینەوە
    - 📝 زیادکردنی تێبینی

---

## 🏪 بەڕێوەبردنی شوێنەکان

### زیادکردنی شوێن

1. کلیک لە **🏪 بەڕێوەبردنی شوێنەکان**
2. کلیک لە **➕ زیادکردنی شوێن**
3. پڕی بکەرەوە:
    - ناو
    - ناونیشان
    - مۆبایل
    - کەرت
    - وێنە
    - لوکەیشن (GPS یان نەخشە)

### دەستکاریکردنی شوێن

- کلیک لە **✏️** → دەستکاری

### سڕینەوەی شوێن

- کلیک لە **🗑️** → دڵنیابوونەوە

### بەڕێوەبردنی مامەڵەکان

- کلیک لە **📋 مامەڵەکان** → زیادکردن / دەستکاری

---

## 📋 بەڕێوەبردنی مامەڵەکان

**بۆ شوێنەکانی وەک پۆلیسی هاتوچۆ:**

1. بچۆ بۆ **شوێنەکان** → کلیک لە پۆلیسی هاتوچۆ
2. کلیک لە **📋 مامەڵەکان**
3. کلیک لە **➕ زیادکردنی مامەڵە**
4. پڕی بکەرەوە:
    - **ناونیشان**: تازەکردنەوەی ساڵنامە
    - **پێداویستییەکان** (هەر دێرێک = یەک):
    - - ماوە: ٣٠ خولەک
- شوێن: هۆڵی سەرەکی
5. پاشەکەوت

---

## 💱 بەڕێوەبردنی دراوەکان

1. کلیک لە **💱 بەڕێوەبردنی دراوەکان**
2. کلیک لە نوسینگەیەک
3. کلیک لە جۆری دراو (USD, EUR, Gold...)
4. دابنێ:
- نرخی کڕین
- نرخی فرۆشتن
- تێبینی (ئارارەزوومەندانە)
5. پاشەکەوت

---

## ⛽ بەڕێوەبردنی سووتەمەنی

1. کلیک لە **⛽ بەڕێوەبردنی سووتەمەنی**
2. کلیک لە بەنزینخانەیەک
3. کلیک لە جۆر (Normal, Super, Oil, Gas...)
4. نرخی نوێ دابنێ
5. پاشەکەوت

---

## 📸 گەلەری شوێن

1. بچۆ بۆ **شوێنەکان**
2. کلیک لە **📸 گەلەری وێنە**
3. کلیک لە **➕ زیادکردنی وێنە**
4. چەند وێنە هەڵبژێرە
5. دیاری بکە:
- وێنەی سەرەکی
- ناونیشان
- کەرت
6. پاشەکەوت

---

## 🏘️ بەڕێوەبردنی گەڕەکەکان

1. کلیک لە **🏘️ بەڕێوەبردنی گەڕەکەکان**
2. کلیک لە **➕ زیادکردنی گەڕەک**
3. پڕی بکەرەوە:
- ناوی گەڕەک
- وەسف
- ناوەندی (Latitude, Longitude)
- ڕەنگ

---

## 🚰 بەڕێوەبردنی ئاگاداری پچڕان

1. کلیک لە **🚰 ئاگاداریەکان**
2. کلیک لە **➕ ئاگاداری نوێ**
3. پڕی بکەرەوە:
- جۆر (کارەبا، ئاو، گاز)
- ناونیشان
- وەسف
- ناوچە کاریگەرەکان
- کاتی چاوەڕوانی
- ناوی فەرمانگە
4. پاشەکەوت

---

## 🏠 بەڕێوەبردنی خانووبەرە

1. کلیک لە **🏠 بەڕێوەبردنی خانووبەرە**
2. کلیک لە **➕ زیادکردنی خانووبەرە**
3. پڕی بکەرەوە:
- جۆر (خانوو، شوقە، زەوی...)
- لیست (فرۆشتن / کرێ)
- نرخ
- زانیاری (ژوور، حەمام...)
- شوێن
- خاوەن (ناو، مۆبایل)
4. پاشەکەوت

---

## 👑 بەڕێوەبردنی ئەدمینەکان

1. کلیک لە **👑 داواکاری ئەدمینەکان**
2. دوو Tab:
- **⏳ چاوەڕوانکراوەکان** → پەسەندکردن یان ڕەتکردنەوە
- **✅ پەسەندکراوەکان** → لابردنی دەسەڵات

---

## 🗄️ بینینی داتابەیس

1. کلیک لە **🗄️ تەیبڵەکانی سۆپابەیس**
2. لیستی تەیبڵەکان دەردەکەون:
- dukan، news، products، orders...
3. کلیک لە تەیبڵێک → بینینی داتا
4. کلیک لە تۆمارێک → وردەکاری

---

## 🔔 ناردنی ئاگاداری

1. کلیک لە **🔔 ناردنی ئاگاداری**
2. پڕی بکەرەوە:
- ناونیشان
- دەق
- ئامانج (هەموو، ئەدمینەکان...)
3. کلیک لە **ناردن**

---

## ⚙️ سیستەم

### 🌤️ کەشوهەوا

1. کلیک لە **🌤️ بەڕێوەبردنی کەشوهەوا**
2. پلەی گەرما و دۆخ دابنێ
3. پاشەکەوت

### 🎨 سلایدەکان

1. کلیک لە **🎨 ڕێکخستنی سلایدەکان**
2. ٥ سلاید هەن:
- **🏪 شوێن** — وێنەی شوێن
- **📰 هەواڵ** — وێنەی هەواڵ
- **🎨 وێنەی خۆت** — وێنەی دەستکرد
3. ڕاکێشە بۆ گۆڕینی ڕیز

---
