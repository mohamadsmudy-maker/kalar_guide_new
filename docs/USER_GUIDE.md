# 👤 ڕێنمایی بەکارهێنەر — User Guide

## 🏠 شاشەی سەرەکی

کاتێک ئەپەکە دەکەیتەوە، شاشەی سەرەکی دەردەکەوێت کە پێکهاتووە لە:

- 📰 **کاروسێلی هەواڵ** — هەواڵەکانی نوێ
- 📢 **دوگمەی سکاڵا** — ناردنی سکاڵا
- 🚑 **دوگمەی فریاکەوتن** — ژمارەکانی گرنگ
- 🚰 **دوگمەی ئاگاداری** — پچڕانی ئاو/کارەبا
- 🏘️ **دوگمەی گەڕەکەکان** — گەڕەکەکانی کەلار
- 🏠 **دوگمەی خانووبەرە** — خانوو، شوقە، زەوی
- 🎯 **بەشەکان** — کاتێگۆرییەکان
- 📰 **لیستی هەواڵ** — هەواڵەکانی زیاتر

---

## 🏪 شوێنەکان

### گەڕان بەدوای شوێن

1. کلیک لە **شوێنەکان** لە ناڤیگەیشنی ژێرەوە
2. لە خانەی گەڕان، ناوی شوێن بنووسە
3. فلترەکان بەکاربهێنە:
    - **حکومی / ناحکومی**
    - **بەشەکان**

### بینینی شوێن لەسەر نەخشە

1. کلیک لە **🗺️** لە سەرەوەی شاشەی شوێنەکان
2. شوێنەکان بە پین دەردەکەون
3. کلیک لە پین → زانیاری

### وردەکاری شوێن

کاتێک کلیک لە شوێنێک دەکەیت، دەبینی:

- 📸 وێنەی شوێن
- 📝 ناو و وەسف
- 📍 ناونیشان
- 📞 ژمارەی مۆبایل
- 💬 واتسئاپ
- 🗺️ لوکەیشن لەسەر نەخشە
- ⭐ هەڵسەنگاندن
- 📋 مامەڵەکان (ئەگەر هەبێت)
- ❤️ زیادکردن بۆ دڵخوازەکان

---

## 📋 ناردنی سکاڵا

1. کلیک لە **📢 ناردنی سکاڵا** لە شاشەی سەرەکی
2. **جۆری کێشە** هەڵبژێرە:
    - خۆڵ و خاشاک
    - کارەبا
    - ئاو
    - ڕێگاوبان
    - تەندروستی
3. **وێنە** دابنێ (لانیکەم ١)
4. **شوێن** لەسەر نەخشە دیاری بکە
5. **دەنگ** تۆمار بکە (ئارەزوومەندانە)
6. **وەسف** بنووسە
7. کلیک لە **🚀 ناردنی سکاڵا**

---

## ⭐ هەڵسەنگاندن

1. بچۆ بۆ شوێنێک
2. کلیک لە **کۆمێنت و هەڵسەنگاندن**
3. ئەستێرەکان دیاری بکە (١-٥)
4. کۆمێنت بنووسە
5. کلیک لە **ناردن**

---

## 💬 چات

1. بچۆ بۆ شوێنێک
2. کلیک لە **💬 چات**
3. نامەیەک بنووسە
4. **وێنە** یش دەتوانیت بنێریت

---

## 🏠 خانووبەرە

1. کلیک لە **🏠 خانووبەرە** لە شاشەی سەرەکی
2. فلترەکان:
    - **فرۆشتن / کرێ**
    - **جۆر** (خانوو، شوقە، زەوی...)
3. کلیک لە خانووبەرەیەک → وردەکاری
4. کلیک لە **📞** بۆ پەیوەندی بە خاوەن

---

## ⚙️ ڕێکخستن

### گۆڕینی زمان

1. بچۆ بۆ **⚙️ ڕێکخستن**
2. **🌍 زمان** هەڵبژێرە:
    - کوردی
    - عەرەبی
    - ئینگلیزی

### گۆڕینی فۆنت

1. بچۆ بۆ **⚙️ ڕێکخستن**
2. **🔤 جۆری فۆنت** هەڵبژێرە
3. **📏 قەبارەی فۆنت** هەڵبژێرە

### گۆڕینی ڕەنگ

1. بچۆ بۆ **⚙️ ڕێکخستن**
2. **🌙 ڕەنگی ئەپ**:
    - Light
    - Dark
    - System

## ❓ پرسیارە باوەکان

### چۆن خانووبەرە زیاد بکەم؟

**وەڵام:** تەنها ئەدمین دەتوانێت. پەیوەندی بە ئەدمین بکە.

### چۆن شوێن زیاد بکەم؟

**وەڵام:** تەنها ئەدمین دەتوانێت لە پانێڵی ئەدمین.

### چۆن سکاڵاکەم ببینمەوە؟

**وەڵام:** لە ئێستادا، دوای ناردنی سکاڵا، ئاگاداریت بۆ دێت کاتێک دۆخەکەی دەگۆڕێت.
